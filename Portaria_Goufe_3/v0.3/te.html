🛡️ Dica de Ouro de TI: O Segredo do Backup Seguro Como a Formatação com Backup será o seu serviço de maior valor, aqui vai o procedimento padrão que os profissionais usam para nunca perder os arquivos do cliente (o que seria um grande problema): 1. Use um HD Externo ou Pen Drive Grande: Tenha um dispositivo de armazenamento exclusivo seu para salvar os dados dos clientes antes de formatar. 2. Onde ficam os arquivos: No Windows, a imensa maioria dos arquivos importantes do cliente estará dentro da pasta do usuário. Vá em: C:\Usuários\NomeDoCliente (ou C:\Users\...). 3. O que copiar: Copie as pastas inteiras de Documentos, Imagens, Downloads, Área de Trabalho (Desktop) e Vídeos. 4. Favoritos do Navegador: Pergunte ao cliente se ele tem senhas ou favoritos salvos no navegador (Chrome, Edge). Se sim, faça a exportação do arquivo de favoritos para recolocar depois. 5. A Regra dos Dois Dias: Após formatar e devolver o computador com os arquivos de volta, não apague o backup do seu HD externo imediatamente. Guarde-o por pelo menos 2 ou 3 dias.
